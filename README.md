# 🏠 Imobiliária Sartori

Site desenvolvido em **React + Vite + Tailwind CSS**, com visual em **verde militar** e foco em praticidade.  
Permite publicar, editar e filtrar imóveis por cidade, além de uma aba institucional “Quem Sou”.

---

## 🚀 Tecnologias Utilizadas

- **React** – estrutura do site  
- **Vite** – ferramenta de build e desenvolvimento rápido  
- **Tailwind CSS** – estilização leve e responsiva  
- **gh-pages** – deploy automático no GitHub Pages  
- **LocalStorage** – armazenamento local dos imóveis  

---

## 💡 Funcionalidades

✅ Listagem de imóveis com busca e filtro por cidade  
✅ Formulário para adicionar, editar ou excluir imóveis  
✅ Aba “Quem sou” com apresentação pessoal  
✅ Layout responsivo e visual limpo  
✅ Dados salvos no navegador (não precisa backend)
